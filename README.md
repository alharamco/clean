# الهرم سمارت أكشن لفيسبوك

## بناء ملف APK (بدون أي كلمات سر)
1. أنشئ مستودعاً جديداً على GitHub، وارفع كل محتويات هذا المجلد في جذر المستودع ومعها المجلد `.github`.
2. تبويب Actions ثم Build APK ثم Run workflow.
3. بعد حوالي 5 دقائق نزّل `AlHaram-APK` من Artifacts وثبّت `app-debug.apk`. احذف النسخة القديمة أولاً.

## خانات الرد
1. الرد العام لكل العملاء.
2. الردود بالكلمات: كل سطر `كلمة1،كلمة2 => الرد` (أول سطر مطابق يُستخدم).
3. الرد لمن لا تنطبق عليه الكلمات.
4. نص الرسالة الخاصة (تُرسل عبر تطبيق ماسنجر بعد الرد العام).
يمكن استخدام `{الاسم}` في أي خانة. مربع "الرد على كل التعليقات حتى النهاية" يكمل حتى آخر تعليق ثم يتوقف.

## تفعيل الرسائل الخاصة (مرة واحدة)
1. يجب أن يكون ماسنجر مثبتاً ومسجلاً بنفس حساب فيسبوك.
2. أندرويد 13 فما فوق: اضغط «معلومات التطبيق» ثم ⋮ ثم «السماح بالإعدادات المقيّدة» (يظهر فقط إذا كان الخيار مقيّداً).
3. اضغط «تفعيل خدمة الرسائل» وفعّل «الهرم سمارت أكشن» في إمكانية الوصول.
4. جرّب على عميلين أو ثلاثة أولاً، ثم زد الحد الأقصى تدريجياً.

## سجل الردود
قابل للتمرير والتحديد والنسخ. الأزرار: نسخ الكل، آخر عملية، أول عملية، مسح. عند الفشل يكتب التطبيق سطر «تشخيص ماسنجر» فيه ما رآه على الشاشة، انسخه وأرسله للمساعدة.

## فتح المنشور
أي رابط تلصقه يُنظَّف من الإضافات التتبعية، وإذا لم يُفتح المنشور يجرّب التطبيق صيغاً بديلة تلقائياً.

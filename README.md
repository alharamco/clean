# الهرم سمارت أكشن لفيسبوك

## بناء ملف APK (بدون أي كلمات سر)
1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع كل محتويات هذا المجلد في جذر المستودع، ومعها مجلد `.github`.
3. افتح تبويب Actions ثم Build APK ثم Run workflow.
4. بعد انتهاء البناء (حوالي 5 دقائق) افتح التشغيل الناجح ونزّل الملف `AlHaram-APK` من قسم Artifacts، وفيه `app-debug.apk`.
5. ثبّته على الموبايل. إذا كانت نسخة قديمة مثبتة فاحذفها أولاً.

## صيغة نص الرد
كل سطر مستقل:
- `كلمة1،كلمة2 => نص الرد` رد خاص إذا احتوى التعليق على إحدى الكلمات.
- سطر عادي بدون `=>` هو الرد الافتراضي.
- `{الاسم}` يُستبدل بالاسم الأول لصاحب التعليق.

# الهرم سمارت أكشن لفيسبوك

## بناء ملف APK (بدون أي كلمات سر)
1. أنشئ مستودعاً جديداً على GitHub، وارفع كل محتويات هذا المجلد في جذر المستودع ومعها المجلد `.github`.
2. تبويب Actions ثم Build APK ثم Run workflow.
3. بعد حوالي 5 دقائق نزّل `AlHaram-APK` من Artifacts وثبّت `app-debug.apk`. احذف النسخة القديمة أولاً.

## خانات الرد
1. الرد العام لكل العملاء.
2. الردود بالكلمات: كل سطر `كلمة1،كلمة2 => الرد` (أول سطر مطابق يُستخدم).
3. الرد لمن لا تنطبق عليه الكلمات.
4. نص الرسالة الخاصة: تُرسل بعد الرد العام إذا ظهر زر مراسلة في صفحة العميل، ومعها مربع تفعيل وحد أقصى للعدد.
يمكن استخدام `{الاسم}` في أي خانة. ومربع "الرد على كل التعليقات حتى النهاية" يجعل التطبيق يكمل حتى آخر تعليق ثم يتوقف.

## عند حدوث مشكلة
انسخ سجل التطبيق كما هو: فيه اسم كل عميل ونص تعليقه وسبب أي تخطي ورابط الصفحة التي فُتحت.
